## ⚙️ Compilation et exécution

### Langage C

Les programmes en **C** ont été écrits et testés avec l'application mobile **MyC**.

Sur ordinateur, vous pouvez compiler un programme avec la commande suivante :

```bash
gcc fichier.c -o programme
```

Puis exécuter le programme :

```bash
./programme
```

### Langage Pascal

Les programmes en **Pascal** ont été écrits et testés avec l'application mobile **MyPascal**.

Sur ordinateur, vous pouvez compiler un programme avec :

```bash
fpc fichier.pas
```

### JavaScript

Les exercices en **JavaScript** ont été écrits avec **Visual Studio Code** et testés dans un navigateur web.

Pour exécuter un programme JavaScript :

1. Ouvrez le fichier HTML dans votre navigateur.
2. Faites un clic droit sur la page.
3. Cliquez sur **Inspecter**.
4. Ouvrez l'onglet **Console**.
5. Consultez les résultats affichés.
