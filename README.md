## ⚙️ Compilation et exécution

Les programmes sont écrits et testés avec les apps mobiles **MyC** (pour le C) et **MyPascal** (pour le Pascal) : ouvre le fichier voulu dans l'app correspondante, puis lance la compilation/exécution depuis son interface.

> Sur ordinateur, les commandes classiques restent valables : `gcc fichier.c -o programme` pour le C, `fpc fichier.pas` pour le Pascal.
